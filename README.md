# WIDE MOTION Films — Vercel Deployment

This is a static website ready for GitHub + Vercel.

## Deploy
1. Extract this ZIP.
2. Upload the files to a GitHub repository.
3. Import that repository into Vercel.
4. Framework Preset: Other.
5. Build Command: leave empty.
6. Output Directory: leave empty / root.
7. Deploy.

The website is fully contained in `index.html`; no separate assets are required.
